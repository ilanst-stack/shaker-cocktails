# שייקר! 🍸 — קוקטיילים מהמלאי שלך

אפליקציית ווב (מותקנת בטלפון כמו אפליקציה) שמציעה קוקטיילים לפי מה שיש לך בבית.

## מה יש בגרסה 0.1
- כניסה עם Google, וכל המידע נשמר ב-Firebase
- מלאי: מצרך "בלי הגבלה" או עם כמות במ״ל
- קוקטיילים מוכנים / כמעט (עם המצרך החסר), לפי בסיס (וודקה, ג׳ין, רום…) וסגנון (קרמי, הדרים, מוגז…)
- "מספיק ל-X כוסות" לפי הכמות במלאי, והצעת החלפות (רום כהה במקום לבן וכו׳)
- מתכון אינפוגרפי: כוס מאוירת עם שכבות לפי היחסים, כמויות במ״ל ופריימים להכנה
- מועדפים ★, "טעמתי" ודירוג 0–5, תמונה משלך לכל קוקטייל
- "בשבילך": המלצות לפי הדירוגים שלך

## מבנה
- `src/firebase-config.js` — פרטי הפרויקט ב-Firebase
- `src/data/` — מאגר המתכונים, מילון המצרכים בעברית, התאמה למלאי, לימוד טעם
- `src/components/` — המסכים
- `firestore.rules` — חוקי האבטחה של מסד הנתונים
- `netlify.toml` — הגדרות הבנייה ב-Netlify

מקור המתכונים: [TheCocktailDB](https://www.thecocktaildb.com).
